# Annoying Chat Prank App

Welcome to the **Annoying Chat Prank App**, a multi-stage, interactive joke application designed to lightly troll your friends (specifically tailored for Akshi) before letting them reach a chat screen. 

## 📝 Description

This is a front-end web application built using standard web technologies (HTML, CSS, JavaScript). It guides the user through a hilarious "prank gauntlet" consisting of 5 distinct stages. Each stage is designed to be slightly frustrating but entirely humorous, culminating in a mock chat interface. 

The project features a sleek, mobile-responsive "dark neon" glassmorphic UI with dynamic animations to make the trolling experience look incredibly polished and premium.

## 🎭 The 5 Stages of the Prank

1. **Terms & Conditions:** The user must agree to ridiculous, self-deprecating terms before proceeding.
2. **Security Check (Captcha):** A fake Captcha asking the user to select squares containing someone with "better fashion sense." 
3. **IQ & Personality Test:** A rigged test where every answer results in a diagnosis of "100% Certified Potato 🥔."
4. **The Vault:** A fake passcode entry screen that ultimately reveals a "WANTED: For being too annoying" poster.
5. **Chatbox:** The final destination. A mock chat interface where you (Kavin) can finally talk to the user after they've survived the gauntlet.

## 🛠️ Technology Stack

- **HTML5:** For the core structure and layout of the app's stages.
- **CSS3:** For the premium styling, custom animations (like background blobs), glassmorphism effects, and responsive design.
- **JavaScript (Vanilla):** For handling the logic of progressing through the stages, the interactive elements (like the moving buttons and mock typing indicators), and the simulated chat responses.

## 🚀 How to Run

1. Clone or download this repository.
2. Navigate to the project folder (`Annoying`).
3. Open the `index.html` file in your preferred web browser. No local server or build tools are required!

Enjoy trolling!
